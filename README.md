# LED Screen Designer V40.04.1

Файл: `LED_Screen_Designer_v40_04_1.py`

Сборка Windows: GitHub Actions → «Build Windows LED Screen Designer»
(запускается при push в `main` или вручную). Результат — архив
`LED_Screen_Designer_v40_04_1_Windows.zip` в разделе Artifacts.

V40.04.1 = V40.04 (автор) + те же исправления и стыковки (V30.90, V30.94).

V30.94.1 = V30.94 (автор) + те же исправления; совместимость с V30.94: вкладки заново центрируются после смены темы.

V30.92.1 = V30.92 (автор) + те же исправления; совместимость с V30.90: градация после сортировки
по столбцу, плашки «Статус»/«УПД» не перекрашиваются темой.

V30.89.1 = V30.89 (автор) + те же перенесённые исправления.

V30.88.1 = V30.88 (автор) + те же перенесённые исправления.

V30.85.1 = V30.85 (автор) + перенесённые исправления: стартовое окно РЖД/МЦД
после mainloop, тема «Светлая / Тёмная», заливка статических строк в «Комплектующих».

V30.74 (сборка): переключатель темы «Светлая / Тёмная» (верхняя панель, выбор сохраняется);
исправлена заливка статических строк во вкладке «Комплектующие».

V30.73 (сборка): стартовое окно РЖД/МЦД открывается после запуска mainloop
(в V30.72 оно создавалось невидимым и блокировало главное окно на Windows);
ошибка окна пишется в `startup_dialog_error.log` и показывается на экране.

Сборка проверяет запуск: главное окно и окно «Выбор проекта» должны быть видны.

Изменения сборки относительно v20.27:
- добавлен `pywin32` (экспорт Word/Excel → PDF через Microsoft Office на Windows);
- сохранён Windows Tcl/Tk packaging fix.

Предыдущая версия (v20.27) доступна в истории репозитория.
