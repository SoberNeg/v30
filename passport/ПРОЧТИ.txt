Утилита заполнения паспортов — прототип V2.0

ЗАПУСК
  Mac:     двойной щелчок по «Запуск_Mac.command»   (или: python3 app.py)
  Windows: двойной щелчок по «Запуск_Windows.bat»   (или: python app.py)
  Нужен Python 3.9+ с tkinter и пакеты python-docx, pillow, pypdf, pypdfium2 (лаунчеры ставят их сами;
  pypdfium2 нужен только для макетов в PDF).

ШРИФТЫ
  Папка «Шрифты»: RussianRail G Pro (титул) и GOST 2.304 type A (весь остальной текст, колонтитулы).
  При запуске программа проверяет, установлены ли они, и предлагает установить (для текущего пользователя).
  После установки перезапустите Word.
  Caveat-Variable.ttf (свободная лицензия OFL, Caveat_OFL.txt) — рукописная дата; ставить в систему не нужно.

ПЕЧАТЬ, ПОДПИСЬ И ДАТА (галочка «Печать, подпись и дата», при каждом запуске выключена)
  Папка «Печати и подписи»:
    Печать.png                → лист выдачи (поверх строк «подпись» и «дата») и гарантийный талон
    Подпись_Заливакин.png     → гарантийный талон, строка «Фамилия и подпись продавца»
    Подпись_Дудин.png         → (если положить) лист выдачи, строка «подпись»
  Несколько вариантов одной подписи: Подпись_Заливакин_1.png, Подпись_Заливакин_2.png —
  для каждого документа берётся случайный.
  Печать масштабируется по реальному диаметру оттиска 38 мм. Каждый оттиск и подпись
  поворачиваются случайно в пределах ±5° и сдвигаются до 8 мм (подпись по вертикали до 3 мм),
  поэтому в соседних документах они не совпадают. Числа — в «Печати и подписи/настройки.json».
  Места в шаблоне видны в Word как «М.П.» и «подпись» — их можно передвинуть мышью.
  ДАТА ОТ РУКИ (ДД.ММ.ГГГГ) — та же, что в поле «Дата продажи»:
    • лист выдачи — на строке «дата» у Дудина, цветом его подписи;
    • гарантийный талон — на месте даты продажи, цветом подписи Заливакина
      (печатная дата «27» октября 2026 г. в этом случае не ставится).
    Цвет берётся из файла подписи автоматически. Каждая цифра со своим наклоном, размером
    и нажимом, вся дата — с поворотом до ±3° и сдвигом до 2 мм. Числа — в «настройки.json» (дата_…).
    Свои цифры: папки «Печати и подписи/Цифры_Дудин» и «Цифры_Заливакин» с файлами 0.png … 9.png
    и точка.png — тогда дата собирается из них, а не из шрифта.
    Если дата продажи не указана — рукописной даты тоже нет. Места в шаблоне — «дата» (пунктир).

КРУГЛЫЕ УКАЗАТЕЛИ
  Тип «Статика МЦД круглый» (шаблон по образцу ASD-L D=1200). В проекте распознаются поле
  «диаметр» или размер вида «D=1200» / «Ø1200». Поле макета 177×80 мм.
  Если макет не выбран — в Приложении 1: «Нет актуальной информации. Ожидается» (во всех статиках).

ДЛЯ ТИПОГРАФИИ (галочка внизу окна, включена по умолчанию)
  • PDF собирается через MS Word, если его нет — через LibreOffice.
  • Номера страниц в оглавлении проставляются по фактическому PDF.
  • Перед задней обложкой добавляются пустые страницы (с колонтитулом и номером, как в образце),
    чтобы число страниц было кратно 4: обложка — 1-я, задняя обложка — последняя.
  • «Лист выдачи изделия», «Гарантийный талон», «Лист тестирования экрана» и «Приложение 1»
    всегда начинаются с новой страницы; на странице Приложения 1 других разделов нет.
  • Без этой галочки оглавление тоже пересчитывается (нужен Word или LibreOffice).

РАБОТА С ПРОЕКТОМ
  1. «Открыть проект…» — сохранённый файл Калькулятора экранов (для пробы: Демо/Демо_проект_Одинцово.json).
  2. Щелчок по изделию в списке — паспорт заполняется сам: наименование, артикул, титул,
     номер макета / серийные номера, тираж, таблица техданных.
  3. «Скачать паспорт». После первого скачивания строка подсвечивается зелёным градиентом,
     в колонке «Скачан» — счётчик (1 раз, 2 раза…).
  Счётчик хранится рядом с файлом проекта: «<файл проекта>.паспорта.json».

ДАТА ПРОДАЖИ
  Поле заполняется сегодняшней датой; «×» — очистить. Если дата пустая, программа спросит
  «Создать паспорт без даты?» — да: в паспорте останется «___» ____________ 20___ г. для записи от руки.

МАКЕТЫ (статика)
  • Макет — картинка (PNG, JPG…) или PDF.
  • PDF: при выборе открывается предпросмотр — страница и рамка обрезки мышью (растянуть,
    передвинуть, тянуть за углы); «Весь лист», «По содержимому» (убрать белые поля).
    В паспорт идёт выбранная область, PNG 300 dpi (папка «<проект>.макеты» рядом с проектом).
    В поле видно «М-0457.pdf, стр. 1, обрезка»; «Обрезать…» — поправить. Двусторонний макет
    одним PDF: стр. 1 → сторона 1, стр. 2 → сторона 2.
  • Выбранные макеты и обрезка запоминаются в «<файл проекта>.паспорта.json».
  • Макет любого размера вписывается в поле Приложения 1 пропорционально и встаёт по центру.
    Поле = размер рисунка в шаблоне: чтобы изменить поле, растяните рисунок в шаблоне в Word.
  • Полей для макета столько, сколько сторон у изделия (колонка «Сторон» / строка
    «Кол-во сторон» в техданных). Двусторонний: рисунки один под другим через одну строку.
  • Файлы макетов ищутся сами рядом с проектом и в папке «Макеты» по номеру макета:
    М-0457.png, М-0458_сторона1.png, М-0458_сторона2.png, М-0459.pdf … (пример — Демо/Макеты).
  • Приложение не разрывается между страницами; «Лист выдачи изделия» всегда с новой страницы.

ИМЯ ФАЙЛА (значения через пробел)

  Динамика: N шт. Артикул СерийныйНомер Проект.docx      2 шт. ASD-TAB P2,5 1450x970 ID 0240925002-0240925003 МЦД-4 Одинцово.docx
  Двойной щелчок по имени внизу окна — изменить вручную (Enter — принять, Esc — отмена,
  пустое имя — вернуть автоматическое). При выборе другого изделия имя снова автоматическое.
  В динамике при тираже > 1 в паспорт идёт диапазон серийных номеров (первый–последний).

РАСЧЁТ
  Шаблоны/правила_расчёта.json — коэффициенты и форматы строк таблицы (кнопка «Правила расчёта»).
  Сейчас это ориентировочные правила, подогнанные под образцы паспортов. Если значение есть
  в файле проекта (масса, мощность, артикул) — берётся из проекта.
  В таблице колонка «Источник»: расчёт / проект / шаблон / вручную.
  Масса и мощность (сумма мощностей блоков питания) — из файла проекта Конструктора V40.04.2,
  те же, что в журнале проекта.
  ПОТРЕБЛЯЕМАЯ МОЩНОСТЬ = сумма мощностей блоков питания одного изделия.
    Статика: LED × 1,5 Вт × 1,2 (запас) → блоки 40/60/100/150 Вт (меньше блоков, затем меньше
      суммарная мощность). LED: односторонний — 60 шт на м² (круг — по площади круга);
      двусторонний — торцевые с шагом 90 мм по длинной стороне ×2 (+ по короткой, если она > 400 мм);
      двусторонний круг — по окружности с шагом 65 мм.
    Динамика: 1 блок 200 Вт на 4 LED-модуля (все стороны) → «максимальная» = сумма блоков,
      «средняя» = 50 % от неё (доля — в правилах расчёта).
    Если в файле проекта нет расчёта Конструктора (старая версия), мощность считается здесь
    по этим же правилам — числа совпадают с Конструктором; ориентировочным остаётся только вес.
  Тип установки — расчётный: одностороннее изделие — «Настенный», двустороннее — «Подвесной».
  Наименование изделия — без размера (размер остаётся в артикуле и в таблице).

ТИТУЛ
  Наименование на титуле ставится только на тёмно-синее поле, не заходя на «квадратики».
  Если строка не помещается, шрифт уменьшается (не меньше 80%); одно слово на строке не остаётся.

ОКНО
  Тема: Светлая / Тёмная — переключатель вверху справа, выбор запоминается.
  Список изделий и поля паспорта прокручиваются колёсиком мыши и тачпадом (Windows, Mac, Linux).
  Сортировка списка: щелчок по заголовку колонки — по возрастанию, ещё раз — по убыванию,
  третий раз — порядок проекта. Выбор запоминается.
  Копировать / вставить / вырезать / выделить всё: Ctrl+C / V / X / A (на Mac ⌘) при любой
  раскладке, а также Ctrl+Insert / Shift+Insert / Shift+Delete; правая кнопка мыши — меню.
  Ctrl+Z — отмена в поле «Наименование на титульном листе».

ФАЙЛЫ ПРОГРАММЫ
  app.py — окно; engine.py — заполнение Word, печать, подписи, дата от руки; calc.py — расчёт;
  project_import.py — чтение проекта; pdf_maket.py — макеты в PDF и обрезка;
  widgets.py — список изделий, буфер обмена; Шаблоны/ — шаблоны паспортов с метками {{...}}.
